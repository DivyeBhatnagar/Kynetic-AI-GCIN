GETTING STARTED • STEP 01

Quickstart: Orchestrating your first training job

Install the Kynetic SDK, inspect real-time compute options with zero cloud lock-in, and dispatch a fault-tolerant training run.

1. Prerequisites

Before initiating execution, verify that your environment satisfies hardware isolation and network protocol parameters:

Runtime Version Python 3.10+ or Linux x86_64
Credential Binding KYNETIC_API_KEY exported to env

2. Installation

Deploy the unified orchestration client into your virtual environment:

bash ~ zsh
$ pip install kynetic

3. Initialize Client & Define Constraints

Switch between native environments to view the orchestration pipeline contract: 

# Import the universal orchestrator
import kynetic as kn

# 1. Establish secure session
client = kn.Client()

# 2. Declare workload envelope with hard SLA constraints
workload = client.workloads.plan(
    model="llama-3-8b",
    training_dataset="s3://internal-weights/curated-tokens-v2",
    constraints=kn.Constraints(
        max_budget_usd=40.00,
        deadline_hours=6.0,
        allow_preemptible_spot=True,
        checkpoint_sync_interval=300, # 5 min automated push
        topology_requirement="sxm5_nvlink"
    )
)

# 3. Simulate and dry-run candidate market rankings
simulation = workload.simulate()
print(f"Optimal provider chosen: {simulation.best_candidate.provider_name}")
print(f"Estimated effective cost: ${simulation.best_candidate.projected_cost:.2f}")

# 4. Dispatch workload with self-healing recovery
run = workload.dispatch(auto_resume=True)
run.stream_telemetry()

4. Workload Constraint Parameters

Technical specifications passed to the autonomous allocation engine:

Parameter Type Default Architectural Behavior
max_budget_usd float None Hard budget clamp. Cluster is cleanly terminated after graceful checkpoint push if reached.
checkpoint_sync_interval int (sec) 300 Zero-overhead delta synchronization frequency into encrypted blob storage.
allow_preemptible_spot boolean True Enables cross-datacenter spot arbitrage with 30-second preemption notice absorption.
topology_requirement string "sxm5_nvlink" Mandates inter-GPU interconnect bandwidth (minimum 900 GB/s bidirectional NVLink).

Troubleshooting & Operational Best Practice

When operating with spot clusters in low-liquidity geo-regions (e.g. eu-central-1), initialize with fallback topology constraints. If preemption rates exceed 2 events per hour, the Kynetic supervisor seamlessly transitions the state to an on-demand node within 4.2 seconds without loss of loss-curve telemetry.
